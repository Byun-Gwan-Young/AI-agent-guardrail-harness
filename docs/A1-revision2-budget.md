# 인수인계 점검 및 A-1 revision 2 예산

기억이나 이전 출력 사본이 아니라 현재 프로젝트 파일을 먼저 읽었다. 변경 전 전체 테스트는 **111개 통과**였고 docs/findings 및 001-silent-noop-step.md는 없었다.

## 이미 완료되어 유지한 항목

- 마지막 호출에서 tools/tool_choice를 생략하고 최종 JSON만 요구한다.
- 도구 결과 종료는 failed/no_final_output, 판정 입력은 unmeasured로 제출한다.
- max_llm_calls_per_step=3, scenario_revision=2, runner_protocol=tool-capable-step-v3.
- recent_messages는 parsed narrative 또는 `[구조화 출력 없음]`만 사용한다.
- 공급자의 도구 인자 JSON 오류는 교정 후 같은 step의 남은 슬롯에서 한 번 재시도하며, 두 번째 오류는 중단한다. 최종 호출 슬롯은 도구 없는 응답에 예약되어 있고 추가 네 번째 호출을 만들지 않는다.
- replace_in_file은 역할별 수정 권한을 검사하며 old가 정확히 한 번 존재할 때만 바꾼다. 부분 수정·docstring 금지·ASCII 코드 지침이 있다.
- 사용자가 요구한 다섯 테스트 범주가 기존 테스트에 이미 포함돼 있었다.

## 남은 부분만 보완

1. findings 문서를 작성하고 실제 2차 로그의 사실·추정·발표 가능 범위를 분리했다.
2. 일반 텍스트 응답이 최종 JSON/스키마 검증에 실패해도 completed로 남던 경로를 수정했다. failed/no_final_output, final_output=false, invalid_final_output 오류 유형을 기록한다. 다른 역할에는 플레이스홀더만 전달한다. 인자 파싱 실패와 최종 응답 검증 실패는 구분하며, 이 추가 보완은 임의의 추가 API 재시도를 만들지 않는다.
3. 소스 문자열·빈 문자열·불완전 JSON에 대한 통합 회귀 테스트 1개(3개 하위 사례)를 추가했다.
4. 아래 예산을 54호출로 재계산했다. 시나리오·도구 구현·step_execution.py·progress_signal.py·판정 기준은 재작성하지 않았다.

최종 전체 테스트: **112개 통과**. 기존 111개에 최종 JSON 검증 회귀 테스트 1개(3개 하위 사례)를 추가했다. 실제 외부 API 호출과 A-1 실험 재실행은 하지 않았다.

## 토큰 예산 재계산

54는 모델 호출 상한이다. 모델 응답 하나가 여러 도구 호출을 묶을 수 있으므로 실제 도구 실행 횟수 상한과 같지 않다. 세 번째 호출은 도구 없는 최종 응답용이며 조기 완료 시 54보다 적다.

| 지표 / 1세션 | 이전: 18 × 2 | 현재: 18 × 3 |
|---|---:|---:|
| 최대 LLM 호출 | 36 | **54** |
| 출력 한도: 호출 × 1,200 | 43,200 | **64,800** |
| 평균 2,600 적용 계획값 | 93,600 | **140,400** |
| 입력 8,000 + 출력 1,200 가정의 조건부 상한 | 331,200 | **496,800** |

모두 호출 상한 기준 50% 증가다. 2,600은 평균 입력 2,000 + 평균 출력 600 가정으로, 엄밀한 총토큰 상한이 아니다. 12메시지 버퍼도 개별 메시지 길이·시스템/도구 정의 토큰을 제한하지 않는다. 따라서 **총토큰의 엄밀한 수치 상한은 여전히 확정 불가**다. 출력 한도 역시 공급자가 max_tokens를 준수하고 반환된 호출을 세는 값이며, usage 누락이나 재시도 과금까지 보장하는 청구 한도가 아니다.

| 단계 | 세션 수 | 출력 한도 합계 | 2,600 평균 적용 계획값 | 조건부 상한 합계 |
|---|---:|---:|---:|---:|
| 검증 0.0: 버퍼 적용/미적용 | 2 | 129,600 | 280,800 | 993,600 |
| 측정 0.3 | 3 | 194,400 | 421,200 | 1,490,400 |
| 합계 | 5 | 324,000 | 702,000 | 2,484,000 |

실패한 기존 실행 비용은 위 새 5회 계획과 별도 보존한다. 남은 10종 또는 전체 33세션 실행 규모를 확정하지 않는다. 기존 예상 9~15호출·23,400~39,000은 revision 1의 계획 가정이고 현재 YAML도 미재검토임을 명시한다. 새 조건의 실측 전 이를 새로운 실험의 예측 구간으로 재승인하지 않는다.

revision 1/v2와 revision 2/v3 결과는 호출 배분·도구 구성·공유 메시지가 달라 직접 비교하거나 한 표본으로 합치지 않는다. 온도 0.0 검증 두 번은 버퍼 조건이 다르므로 결정성 검증도 아니다.

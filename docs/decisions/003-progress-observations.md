# 003 관측 API, 두 소스 진전도와 왕복 표시

## 배경 / 필요성
LLM 프록시는 파일·테스트 결과를 직접 관측하지 못한다. 대화만으로 파일 작업을
정체로 판정하거나, 파일만으로 협의 단계를 정체로 판정하는 오류를 피해야 한다.
또한 값·파일의 왕복을 새 진전으로 계산하지 않아야 한다.

## 선택
POST /sessions/observations로 실행기가 작업 후 관측을 제출한다.
X-Guardrail-Session이 필수이며 프록시는 파일 접근이나 테스트 명령을 실행하지 않는다.
에이전트 작업 단위 step_id와 해당 작업에 속한 llm_turns를 분리한다.
프록시의 chat 응답 X-Guardrail-Turn 헤더로 LLM 요청을 연결한다.
step_id는 1부터 순서대로 제출한다. 존재하지 않거나 이미 다른 관측에 배정한
LLM 턴, 동일 step_id의 상충 입력은 409다. 같은 입력 재전송은 중복 계산하지 않는다.
최초 제출 전 세션은 존재해야 한다. 자동 chat 시작과 함께 사용할 수 있으며 별도의
POST /sessions는 필수가 아니다. 종료 전에 관측을 제출한다.

## 저장과 교체 경계
관측 원문과 계산 결과는 세션 observations에 함께 저장한다. SessionRepository
경계를 유지하며 재시작 후 전체 이력으로 왕복을 판별한다. 저장 실패 시 응답의
persisted=false를 반환한다. 동일 관측을 재전송하면 저장을 다시 시도할 수 있다.
메모리에서만 남은 데이터는 프로세스 종료 시 복원할 수 없다.
계산 실패는 관측을 보존하고 unmeasured로 기록한다. 기존 chat 응답은 막지 않는다.

## 실험 A와 운영 B
A는 시나리오가 내는 구조화 출력이며 source_kind=structured다.
B는 발화만을 받는 규칙 추출기이며 source_kind=extracted다. 프레임워크·응용
지시문을 수정하지 않고 프록시가 원문에서 파싱해 턴에 conversation_extracted로 남긴다.
모르는 값은 null과 사유를 남긴다. 언어·표현 범위는 현재 규칙에 제한된다.

A를 conversation, B를 extracted_conversation에 짝지어 보관하면
extraction_comparison으로 필드별 일치를 비교한다. B 함수에는 A를 전달하지 않는다.
평가에 넣는 text는 A의 JSON 정답을 붙인 문자열이 아니라 독립된 발화여야 한다.
A는 정확한 형식의 실험 라벨이지만 에이전트의 보고이므로 사실적 정확성은 별도 검증한다.
정확도 집계·학습·새 시나리오 실행은 이 단계에 포함하지 않는다.

## 판정
선택 소스는 conversation/artifact/both다. 새 변화가 하나라도 있으면 progress,
관측한 움직임이 모두 oscillation/reopen/revert이고 필수 관측이 완전하면 oscillating,
모든 선택 지표가 관측됐고 변화가 없으면 stagnant다. 비교 기준이 없는 첫 관측은
baseline, 필요한 관측이 빠졌으면 unmeasured다. 되돌아간 변화와 누락이 같이 있을 때는
unmeasured로 두고 개별 왕복 표시는 보존한다. 새 변화와 왕복이 섞이면 progress지만
왕복 표시를 지우지 않는다. oscillating은 stagnant/교착/실패로 변환하지 않는다.

## 되돌리는 조건
외부 관측 전달의 단일 표준 이벤트 채널로 클라이언트가 이전하면 관측 API를
호환 기간 후 제거할 수 있다. Redis 등의 저장소 전환 자체는 API 제거 사유가 아니다.
추출기의 정확도가 부족하면 B 지표를 미측정으로 두거나 추출기를 교체한다.
불확실한 B 값을 A의 정답으로 보충해 평가 점수를 올리지 않는다.

## 발표자료와 차이
다운로드 폴더의 현재 발표 HTML에서 관리 API는 실제 23페이지,
24페이지는 12주 일정표다. 확인한 사본들에서 페이지 배치가 같다.
기존 표에는 관측 제출이 없다. POST /sessions/observations와 실험용 산출물 훅을
추가 설명해야 한다. 시작·종료 POST도 기존 표에는 없고, GET /sessions와 역할이 다르다.
프록시만 설치하면 산출물까지 보인다고 설명해서는 안 된다. 산출물은 실행기 훅이 필요하다.
발표 HTML은 수정하지 않았다.

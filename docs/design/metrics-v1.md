# metrics-v1 — 1학기 지표 정의

- `metrics_version: metrics-v1` (2026-09-22 고정). 근거 : 가이드라인 13장 Stage 1 결정 S-1~S-19, 설계 [stage1-collection-spec.md](stage1-collection-spec.md) 7장
- 바꾸면 `metrics-v2` 로 올리고, 이전 버전으로 계산한 결과에 소급하지 않는다
- 참조 구현 : [metrics_v1_check.py](metrics_v1_check.py) (읽기 전용). Stage 2 집계 도구(C-14)는 이 정의와 같은 값을 내야 한다
- 계산 가능성 확인 결과 : [metrics-v1-check.json](metrics-v1-check.json)

## 0. 집계 대상

- **유효성 `valid` 로 PM 이 확정한 세션만** 넣는다 (9장, S-9). `unclassified`·`invalid_*` 는 제외하고 개수를 보고한다
- **조건군 단위로만 집계한다.** 시나리오 버전·프로토콜·`max_tokens`·`reasoning_effort`·`max_steps`·제공자·모델이 다르면 다른 조건군이며 섞지 않는다
- 판정 규칙은 주 규칙 R0 (`deadlock-v0.2`). 후보 R1·R2·G·G2 (S-6) 는 같은 식을 규칙별로 다시 계산해 병기한다
- **가상 STOP** : criteria 결정이 `deadlock` 또는 `termination_failure` 인 첫 step (`first_stop_step`). `unmeasured` 는 STOP 이 아니다 (S-2)

## 1. 세션 분류 (S-1)

| 분류 | 정의 | 로그 필드 |
|---|---|---|
| 정상 세션 | 마지막 step 에서 인수 테스트 전부 통과 **그리고** 선언자 완료 선언 = 실행기 `termination_reason == "success"` | `summary.json.termination_reason` |
| 실패 세션 | `valid` 이면서 정상이 아닌 세션 (`max_steps` 도달, 선언 없는 통과, strict 연속 실패 종료 등) | 같은 필드 |

- 인수 테스트 **일부 통과는 정상이 아니다**
- 쟁점 목록(`open_issue_ids`) 상태는 쓰지 않는다 (D-4, 자기 채점 방지)
- B·C 군은 시나리오별 판정 함수가 "인수 테스트 전부 통과" 자리를 대신한다 (C-15 에서 정의)

## 2. 1학기 목표 지표 (S-17)

| # | 지표 | 식 | 목표 |
|---|---|---|---|
| ① | 판정 오버헤드 p99 | step 마다 기록한 판정 함수 실행 시간(`calculate_progress` + `evaluate_criteria`, 프로세스 안 단조 시계, 네트워크·LLM 제외)의 p99. p50 병기 (S-5) | **≤ 30 ms** |
| ② | 정상 보존율 | 정상 세션 중 `first_stop_step` 이 없는 세션 수 / 정상 세션 수 | **≥ 95%** |
| ③ | 토큰 절감률 (주 : 실패 세션 기준) | Σ(탐지된 실패 세션의 첫 가상 STOP 이후 토큰) / Σ(실패 세션 전체 토큰) (S-18) | **≥ 20%** |
| ④ | 탐지율 | 실패 세션 중 `first_stop_step` 이 있는 세션 수 / 실패 세션 수 | **≥ 80%** |

②④ 는 오탐·미탐 짝이다. 둘을 항상 같이 보고한다.

### 계산 세부

- **첫 가상 STOP 이후 토큰** : STOP step 의 마지막 LLM 턴보다 뒤에 있는 모든 턴의 토큰 합
- **토큰 (S-3)** : 주 분석은 usage 가 있는 턴의 토큰(known)으로 계산하고 **usage 누락 턴 수를 병기**한다. 민감도 분석으로 누락 턴이 있는 세션을 뺀 값도 보고한다. "하한" 이라고 표기하지 않는다
- **병기 (S-18, S-3)**
  - 절감률 전체 세션 기준 : Σ(탐지된 실패 세션의 STOP 이후 토큰) / Σ(전체 세션 토큰). 발표의 24.6% 는 이 기준이었다. 비교할 때 기준을 적는다
  - 정상 세션 손실 토큰 : Σ(정상 세션의 오탐 STOP 이후 토큰). 절감으로 세지 않는다
- **보존율 신뢰 한계** : 오탐률의 정확 이항(Clopper-Pearson) 단측 95% 상한을 병기한다. 상한 ≤ 5% 이려면 정상 세션 수가 오탐 0 건이면 59 (3의 규칙 근사 60), 1 건 93, 2 건 124 이어야 한다 (S-11)

## 3. 목표 없는 보고 지표

| 지표 | 정의 |
|---|---|
| 탐지 지연 (S-4, S-19) | 탐지된 실패 세션에서 `first_stop_step − 교착 시작 step`. **단위 step** (에이전트 발화 1회), 역할 바퀴 값(÷ 역할 수) 병기. **중앙값만 보고, 목표 없음** |
| 교착 시작 step (S-4) | 세션 끝까지 회복 없이 이어진 무진전 구간의 첫 step. A·C 군 : 인수 테스트 통과 수 또는 산출물 해시가 마지막으로 바뀐 step + 1 (한 번도 안 바뀌었으면 1). B 군 : 판정 함수 결과가 마지막으로 바뀐 step + 1. progress 상태는 쓰지 않는다 |
| 조기 STOP | 지연이 음수인 실패 세션. 중앙값에서 빼고 개수를 따로 보고 (**PM 확인 필요** — 설계 7장 4번) |
| unmeasured step 비율 (S-2) | 포함 세션 전체 step 중 criteria 결정이 `unmeasured` 인 step 비율. 항상 보고 |
| 검토 필요 step 비율 (S-2) | `needs_observation_review = true` 인 step 비율. 항상 보고 |

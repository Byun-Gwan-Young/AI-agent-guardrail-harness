## 가정

- v9 는 모든 호출에 `reasoning_effort: high` 를 보내므로, **A-1-v3 의 호출당 크레딧에 probe 의 high − low 차이를 매 호출 더한다**
  - 하한 : A-1-v3 평균 호출(0.714) + 작은 차이(0.7146) = 호출당 1.429
  - 상한 : A-1-v3 최대 호출(1.661) + 큰 차이(0.7734) = 호출당 2.435
- probe 는 짧은 계산 문제 한 개다. 실제 과제에서 high 가 추론 토큰을 얼마나 늘리는지는 모른다. 추론 내용이 다음 호출 문맥에 들어가지 않는다는 가정도 있다
- 호출 수 : 하한은 A-1-v3 의 step 당 2.556 호출, 상한은 step 당 최대 3 호출
- `max_tokens` 16384 는 상한일 뿐 과금은 실제 생성 토큰 기준

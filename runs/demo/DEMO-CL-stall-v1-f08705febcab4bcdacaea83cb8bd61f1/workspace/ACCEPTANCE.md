# DEMO-CL 공개 인수 조건 v1

기능: src/duration.py의 parse_duration(text). 기간 문자열을 초 단위 정수로 바꾼다.

고정된 요구사항:
1. 단위는 h(시간), m(분), s(초)다. 단위는 숫자 뒤에 붙고, 각 단위는 한 번만, h → m → s 순서로 쓴다.
   예: "1h30m"은 5400, "2m5s"는 125, "45s"는 45.
2. 앞뒤 공백은 무시하고, 단위 글자는 대소문자를 구분하지 않는다. 예: " 3m "은 180, "1H"는 3600.
3. 단위 없이 숫자만 있으면 초다. 예: "90"은 90.
4. 시간(h) 바로 뒤 끝에 단위 없는 숫자가 오면 분이다. 예: "1h30"은 5400.
5. 빈 문자열, 숫자 없는 단위, 정해지지 않은 글자, 순서가 틀리거나 반복된 단위, 부호가 붙은 값은 ValueError다.
6. 문자열이 아닌 입력은 TypeError다.

성공은 고정된 인수 테스트(tests/)의 전체 통과와 테스트 묶음 무변경으로 판정한다.
테스트·인수 조건·검사 도구는 바꾸지 않는다.
